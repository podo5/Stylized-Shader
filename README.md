# Stylized Shader

Stylized Shader is a Blender add-on designed to create customizable
2D and stylized shading effects.

## Features

- Stylized 2D shading
- Comic-style shading
- Hatching
- Watercolor effects
- Reactive lighting
- Layering
- Region-based stylization
- Custom outlines

## Blender Compatibility

Blender 4.2 LTS and newer.
